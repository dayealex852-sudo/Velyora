Vellura

Présentation

Vellura est une application mobile conçue pour faciliter la découverte, la présentation et la vente de produits en ligne.

Objectif

L’objectif de Vellura est de proposer une plateforme simple, moderne et facile à utiliser, permettant aux utilisateurs de consulter des produits, d’obtenir des informations et de réaliser leurs achats.

Fonctionnalités prévues

- Accueil avec présentation de Vellura
- Catalogue de produits
- Recherche de produits
- Fiches détaillées des produits
- Panier
- Commande
- Compte utilisateur
- Interface simple et adaptée aux téléphones Android

Installation

La première version de Vellura sera développée progressivement. Une fois l’application prête, elle pourra être installée sur un téléphone Android.

Développement

Vellura est un projet en cours de développement. Les fonctionnalités et l’interface seront améliorées progressivement.

Version

Version initiale : 0.1.0
